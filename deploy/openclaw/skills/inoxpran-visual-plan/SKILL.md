# inoxpran-visual-plan

Description: Plan realistic cover and inline images for an Inoxpran SEO article.

Output:
- article type
- one cover plan
- 2-4 inline plans tied to meaningful H2/H3 headings
- dimensions, purpose, scene, and source preference for every item

Standards:
- Cover master intent: 1600x900; display output: 1200x675.
- Inline output: 1200x800 or 1200x675.
- Prefer realistic Vietnamese home kitchens and practical stainless cookware.
- Do not place an image after every heading.

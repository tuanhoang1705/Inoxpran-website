# seo-image-metadata

Create natural image alt text, title, caption, and SEO-safe filenames.

Allowed skill:
- `inoxpran-image-metadata`

Rules:
- Describe the visible scene naturally.
- Never repeat the target keyword more than once in alt text.
- Keep captions short and useful to the surrounding section.
- Do not upload, publish, use shell, access MongoDB, or use the admin UI.
